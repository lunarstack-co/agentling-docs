# Agentling brand assets

The mark is a lowercase a whose stroke runs on along the baseline and out of the loop. It is black and white only.

## Where each file goes

| Place | File | Size |
|---|---|---|
| Site header | `src/components/icons/mark.tsx` (uses the small cut, follows the text colour) | 18 px |
| Favicon | `web/icon.svg` (black in light mode, white in dark), `web/favicon.ico` | 16 to 48 px |
| Apple touch icon | `web/apple-icon.png` | 180 |
| PWA icons | `web/icon-192.png`, `web/icon-512.png`, `web/icon-512-maskable.png` | 192, 512 |
| README header | `logo/agentling-horizontal-black.svg` with `-white.svg` for dark mode | 56 px high |
| LinkedIn page logo | `social/avatar-on-black-400.png` or `avatar-on-white-400.png` | 400 x 400 |
| LinkedIn cover | `social/linkedin-cover-1128x191.png` | 1128 x 191 |
| X profile picture | `social/avatar-on-black-400.png` | 400 x 400 |
| X header | `social/x-header-1500x500.png` | 1500 x 500 |
| GitHub organisation avatar | `social/avatar-on-black-1000.png` | 1000 x 1000 |
| GitHub social preview (repo settings) | `social/github-social-preview-1280x640.png` | 1280 x 640 |
| Link previews elsewhere | `social/open-graph-1200x630.png` | 1200 x 630 |

On LinkedIn and X, the banner text sits right of centre and high, clear of the profile picture that covers the bottom left.

## Logo files

- `logo/agentling-symbol-black.svg`, `-white.svg`: the symbol, for 24 px and up.
- `logo/agentling-symbol-small-black.svg`, `-white.svg`: the heavier cut for 24 px and below.
- `logo/agentling-horizontal-*.svg`, `logo/agentling-stacked-*.svg`: lockups with the wordmark (Mona Sans 600, outlined).
- `logo/png/`: large PNGs for slides and documents.

The white versions are drawn slightly thinner, because white on black looks heavier.

## Rules

- Black on light grounds, white on dark grounds. No colours, tints, outlines, shadows or gradients.
- Leave clear space on every side equal to the height of the bottom stroke.
- Keep the counter's square corner square.
- Below 80 px wide, use the symbol instead of the horizontal lockup.
